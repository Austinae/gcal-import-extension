# Privacy Policy for GCal Quick Import

Last updated: November 25, 2025

This policy explains how the GCal Quick Import browser extension uses information.

## Summary

The extension does not sell your data. It does not send your calendar files to the developer. It does not use analytics or tracking.

## Where the extension runs

The extension runs only on https://calendar.google.com. It does not run on other websites.

## Data the extension handles

Calendar files you choose. When you drop or select a file, the extension reads that file in your browser. It uses the file to complete Google Calendar import. The developer does not receive the file on a separate server.

Google Calendar. Import uses Google settings and Google import pages while you are signed in. Google privacy rules and terms apply to Google Calendar. See Google Privacy Policy and Terms of Service at policies.google.com.

Settings you save. If you set import mode or a default calendar name in the extension menu, Chrome stores those values locally. Chrome may sync them if you use Chrome sync. Short import job data may stay in session storage until import finishes.

## What the developer does not collect

The developer does not collect or receive personally identifiable information, health information, financial information, or passwords.

The developer does not collect web history, keystrokes, or general browsing outside import.

The developer does not store your files or calendar content on developer servers.

## Permissions

Host access for calendar.google.com. The extension shows import controls and completes import on Google pages.

Storage. The extension saves your optional settings and short import job state on your device.

Scripting. The extension attaches your file to Google import controls on the Import settings page. Google requires this for automated import.

## Children

The extension is not for children under 13.

## Changes

We may update this policy. We will change the last updated date when we do.
